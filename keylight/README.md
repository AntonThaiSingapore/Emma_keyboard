# Keylight — Ten-Finger Typing Club

A responsive, browser-only typing practice game. No build step or external JavaScript dependencies are required.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static server. For example:

```sh
npx serve .
```

## Deploy to Vercel

The Vercel project uses this folder (`keylight/`) as its root. The static entry point is `index.html`; no build command is required.

## Features

- Five progressive levels: home row, reaches, words, titles, and full sentences
- Full desktop keyboard with active key and home-row markings
- Correctly oriented left and right hand illustrations with the active finger highlighted along its full length
- Live score, accuracy, streak, and level progress
- Main-page controls for text size, level pass score, background interval, and wrong-key sound
- Background image rotation, defaulting to 15 seconds, plus player-added HTTPS image URLs
- Top-left YouTube and Spotify embed player; paste a video, track, album, or playlist link and press play in the embed
- Encouraging feedback, pause, and saved level unlocks
- Responsive layout and keyboard-only play

YouTube and Spotify audio is played by their embedded players. The game does not download or rehost music. Playback begins only when the player starts it.
