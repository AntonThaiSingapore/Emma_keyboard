# Keylight — Ten-Finger Typing Club

A responsive, browser-only typing practice game. No build step or external JavaScript dependencies are required.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static server. For example:

```sh
npx serve .
```

## Deploy to Vercel

Import this folder/repository as a project in Vercel. Choose **Other** as the framework preset and leave the build command blank. The static output is the project root and the entry point is `index.html`.

## Features

- Five progressive levels: home row, reaches, words, titles, and full sentences
- Full desktop keyboard with active key and home-row markings
- Finger guidance with translucent hand illustrations and highlighted fingertip
- Live score, accuracy, streak, and level progress
- Adjustable practice text size and level pass threshold
- Optional wrong-key sound and original synthesized ambient music
- Encouraging feedback, pause, and saved level unlocks
- Responsive layout and keyboard-only play

Practice titles are short names only; no lyrics, commercial recordings, group photos, logos, or likenesses are included. The backdrop uses an original abstract stage-light aesthetic.
